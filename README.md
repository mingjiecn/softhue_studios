# SoftHue Studios

A Next.js website for selling original paintings and offering custom design services.

## Features

- **Studio Branding**: SoftHue Studios displayed prominently at the top
- **Paintings Gallery**: Browse and purchase available artwork with 20% off opening sale pricing
- **Custom Design**: Commission one-of-a-kind pieces tailored to your space and style
- **Opening Sale Promotion**: 20% off sitewide banner on the main page

## Requirements

- Node.js 18.17.0 or later

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
